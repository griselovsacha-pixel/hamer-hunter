# Hamer Hunter - Ultimate Bug Bounty Scanner & Proxy

Сканер уязвимостей «всё в одном» с встроенным прокси, OSINT и автопробами инъекций.  
Находит проблемы быстрее чёрных хакеров и даёт точные инструкции по исправлению.

## Быстрый деплой на Render

1. **Форкните этот репозиторий** на GitHub.
2. Зайдите на [Render](https://render.com), создайте новый Blueprint.
3. Подключите свой репозиторий и укажите путь к файлу `render.yaml`.
4. Render автоматически развернёт:
   - Веб-интерфейс (hamer-hunter-web)
   - Прокси-сервер (hamer-hunter-proxy)
   - Redis и Worker
5. После деплоя откройте URL веб-сервиса.
6. (Опционально) Добавьте переменные окружения `SHODAN_API_KEY` и `HUNTER_API_KEY` для OSINT-модулей.
7. Готово! Вводите URL и сканируйте, либо подключайте браузер к адресу прокси.
